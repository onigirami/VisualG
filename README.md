# 🎓 VisualG - Cronograma de Lógica de Programação

## Sobre o Projeto

Este repositório contém o **cronograma de estudos e exercícios** das aulas de **VisualG** ministradas pelo professor **Paulino Viana** na **Universidade UNIESBAM** em Manaus, AM.

O VisualG é uma ferramenta educacional fundamental para aprender **lógica de programação** de forma visual e interativa, permitindo que alunos entendam conceitos-chave antes de avançar para linguagens de programação mais complexas.

## 📚 Conteúdo

- **Cronograma de Aulas**: Aulas ministradas duas vezes por semana
- **Exercícios Práticos**: Atividades para consolidar o aprendizado
- **Soluções**: Resoluções comentadas dos exercícios
- **Materiais de Apoio**: Slides das aulas com exercicios

## 🎯 Objetivos

- Aprender os fundamentos de lógica de programação
- Desenvolver raciocínio lógico estruturado
- Praticar algoritmos básicos
- Preparação para linguagens de programação

## 📖 Como Usar Este Repositório

1. Clone o repositório
2. Navegue pelos tópicos na ordem sugerida
3. Complete os exercícios propostos
4. Compare suas soluções com as fornecidas
5. Participe das discussões em caso de dúvidas
